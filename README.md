# Project 5: Longest Common Subsequence

A C++ project for Data Structures and Algorithms II that computes and displays Longest Common Subsequence (LCS) results.

The program reads input strings from text files, processes them using the LCS implementation, and prints the results to the console.

Please refer to **UsersManual.pdf** in the root directory of this project for more detailed information and how to run the program.
